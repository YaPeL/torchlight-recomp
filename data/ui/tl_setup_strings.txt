The disk may be read-only, or the folder may belong to another user. Move the game to a folder of yours first. = El disco puede ser de solo lectura, o la carpeta puede pertenecer a otro usuario. Mueve antes el juego a una carpeta tuya.
Folders such as Program Files can only be written by an administrator. Move the game to a folder of yours (in Documents, or on another drive) first. The disk may also be read-only. = En carpetas como Archivos de programa solo puede escribir un administrador. Mueve antes el juego a una carpeta tuya (en Documentos, o en otra unidad). El disco también puede ser de solo lectura.
The disk may be read-only (a disk image), or macOS may be running the game from a temporary place. Move it to Applications or another folder first. = El disco puede ser de solo lectura (una imagen de disco), o macOS puede estar ejecutando el juego desde un lugar temporal. Muévelo antes a Aplicaciones o a otra carpeta.
It may belong to another user, or be on a read-only disk: check its permissions and its disk, then start again. = Puede pertenecer a otro usuario, o estar en un disco de solo lectura: comprueba sus permisos y su disco, y vuelve a empezar.
If it is in a place such as Program Files and was made while the game ran as administrator, only administrators can write in it: move the game and this folder to a folder of yours, or give your account write access in its Properties (Security tab), then start again. It may also be on a read-only disk. = Si está en un lugar como Archivos de programa y se creó mientras el juego se ejecutaba como administrador, solo los administradores pueden escribir en ella: mueve el juego y esta carpeta a una carpeta tuya, o da a tu cuenta permiso de escritura en sus Propiedades (pestaña Seguridad), y vuelve a empezar. También puede estar en una unidad de solo lectura.
It may be on a read-only disk (a disk image), or macOS may be running the game from a temporary place: move the game and this folder to Applications or another folder, then start again. = Puede estar en un disco de solo lectura (una imagen de disco), o macOS puede estar ejecutando el juego desde un lugar temporal: mueve el juego y esta carpeta a Aplicaciones o a otra carpeta, y vuelve a empezar.
Running as administrator = Ejecutándose como administrador
The game is running as administrator, so the folder made now will belong to the administrators. In a place such as Program Files, the game started normally will then not be able to write in it. Close it and start it normally, unless you will always start it as administrator. = El juego se está ejecutando como administrador, así que la carpeta creada ahora pertenecerá a los administradores. En un lugar como Archivos de programa, el juego iniciado normalmente no podrá escribir en ella. Ciérralo e inícialo normalmente, salvo que siempre vayas a iniciarlo como administrador.
